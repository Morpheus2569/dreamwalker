# DreamWalker

The DreamWalker brand hub and accountability coaching site — built and maintained by Ashè for Morpheus.

## What's here

- **`index.html`** — Brand hub homepage: the DreamWalker story, the three ventures (coaching, printables, Grace of Sanctuary), and contact.
- **`coaching.html`** — Accountability coaching landing page: who it's for, how it works, founding-client pricing, FAQ, and booking.
- **`styles.css`** — Shared stylesheet (dark + gold theme).

## Local preview

Open `index.html` in any browser, or serve the folder:

```bash
cd dreamwalker-site
python3 -m http.server 8000
```

## Publishing

Push to `main` and enable **GitHub Pages** (Settings → Pages → Deploy from branch → `main` / root) for a live site at `https://morpheus2569.github.io/dreamwalker/`.
